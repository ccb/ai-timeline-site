# AI Timeline

An interactive, multi-lens timeline of artificial intelligence, built for *AI for All*, the
gateway course of Penn's AI+X initiative (Chris Callison-Burch and Bhuv Jain).

**View it:** https://ccb.github.io/ai-timeline-site/

This repository holds only the published page and its photos. Every image carries a
credit line and a link to its source. Feedback is welcome: email ccb@upenn.edu.
